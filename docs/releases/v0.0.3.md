# 轻邮 Lightmail v0.0.3

修复正文已经缓存、邮件列表却仍显示“正文将在打开时加载”的问题。

- 启动时从已有正文补回缺失摘要，即使旧版的摘要迁移已经执行过。
- 正文预加载和阅读命中缓存时，同步修复对应邮件及 Gmail 标签副本的摘要。
- 同步重新建立邮件目录时，复用现有正文生成摘要，无需再次下载。

缓存规则保持不变：每个邮箱各保留最新 20 封正文，超出范围的旧正文按需读取，已生成的摘要保留。

## 升级

需要 Apple Silicon Mac、macOS 15+。退出应用，使用 `Lightmail-v0.0.3-macos-arm64.zip` 中的 `轻邮.app` 替换旧版。首次启动会自动修复已有缓存的摘要。

早期预览版仍使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。升级后 macOS 可能要求重新授权钥匙串，密码仅在系统弹窗中输入。源码和 vendored Rust 依赖见 `Lightmail-v0.0.3-source.tar.gz`，校验值见 `SHA256SUMS.txt`。

## 验证

三个针对性回归场景先复现旧版失败，再验证修复：已执行迁移后的摘要缺失、邮件目录重新建立、预加载命中缓存时的 Gmail 标签摘要恢复。常规构建、协议、渲染及缓存检查纳入发布验证。
