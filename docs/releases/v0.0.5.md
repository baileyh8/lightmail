# 轻邮 Lightmail v0.0.5

整合 PR #3 的 Windows 原生客户端迭代，并补齐 Mac 授权和内嵌图片兼容性修复。

## 变化

- Windows 改用 GPUI Kit + Blitz 渲染邮件，无需 WebView2。新增托盘、单实例保护和单邮箱代理配置；点击邮件链接前显示实际地址供确认。
- 窄窗口工具栏收起按钮文字，保留图标、提示和可访问性名称，为窗口按钮及拖动区域预留空间。
- Mac 和 Windows 共用 Rust 授权提交流程。更改已有邮箱身份会在登录前被拒绝；重新授权与后台令牌刷新使用同一把账号锁，保存失败时恢复原凭证。
- Mac 点击“显示图片”后可以显示受限的 MIME CID 内嵌图片。默认仍不加载图片，脚本、框架和外部样式表继续被阻止。
- 保留每个邮箱独立的最新 20 封正文缓存，以及旧邮件摘要；普通附件仍按需下载。
- 源码包保留 Git 依赖的 vendor 映射，支持从打包依赖构建。

## 安装与验证范围

Mac 需要 Apple Silicon 和 macOS 15+；Windows 需要 Windows 10 1809+ / 11 x64。下载后可用 `SHA256SUMS.txt` 校验。Mac 尚未公证，Windows 尚未代码签名。

本轮检查包含共享核心回归、Mac 实际 WKWebView 渲染、回环邮件及翻译服务，以及 Windows 原生 UI 和安装／卸载验收。具体结果以本版本对应的 CI 和验收记录为准。

没有执行真实邮箱发信。Windows 真机人工验收、真实服务商完整登录与持续收发、输入法及跨显示器行为尚未完成；自动检查不代表这些场景已经通过。Blitz 不提供完整浏览器的所有 HTML/CSS 能力。
