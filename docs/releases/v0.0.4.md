# 轻邮 Lightmail v0.0.4

新增 Windows 原生客户端，并将两端共用的业务流程集中到 Rust。macOS 继续使用 SwiftUI / AppKit，Windows 使用 GPUI 和系统 WebView2。

## 变化

- 同步、IDLE、预加载、OAuth、凭证刷新、延迟发送、LLM 翻译与 Markdown 导出由同一个 `MailApplication` 管理。界面只处理显示、交互和系统适配。
- Windows 支持多账号、邮件与文件夹列表、HTML 阅读、草稿、回复与转发、附件、翻译和复制；凭证保存在 Windows Credential Manager。
- Windows 界面对齐 Mac 的三栏布局、紧凑字号、绿色选中态及设置／写信弹窗。整行可点选，表单可滚动，小屏幕启动时窗口自动适配。
- 保留现有数据库、账号 ID 与钥匙串键名。每个邮箱仍独立保留最新 20 封正文，旧摘要继续保留。
- 正文排版与安全策略共用 Rust 实现；Windows 阅读器异步创建，避免首次打开邮件时重入绘制流程。

## 安装

- **Mac**：Apple Silicon、macOS 15+；退出旧版后，用 `Lightmail-v0.0.4-macos-arm64.zip` 中的应用替换旧版。
- **Windows**：Windows 10 1809+ / 11 x64，需 WebView2 Runtime；可选按用户安装器或便携 ZIP。卸载保留本地邮件与草稿。
- **源码**：`Lightmail-v0.0.4-source.tar.gz` 附带锁定的 Rust 依赖；下载文件可用 `SHA256SUMS.txt` 校验。

macOS 尚未做 Developer ID 公证，Windows 尚未代码签名。本地临时签名更新后，macOS 可能要求重新授权钥匙串；密码只填系统弹窗。Google OAuth 仍使用自己的 Desktop Client ID。

## 验收范围

CI 覆盖三平台 Rust 服务测试与回环 TLS IMAP/SMTP、HTTP/SOCKS 代理、OAuth PKCE／并发刷新、Chat JSON/SSE、取消与重复发送防护。macOS 另检查 Swift、实际 WebKit 排版和 500 次阅读回归；本机使用隔离副本抽查了 6 封真实缓存 HTML，未修改真实邮箱或发送邮件。

Windows 在托管 runner 上运行原生窗口与 WebView2，检查空白处点选、正文／链接／滚动、图片与脚本限制、剪贴板、设置、草稿、60 次阅读器复用、凭据读写，以及安装、正常退出、卸载后保留数据。

暂无 Windows 真机人工验收，也未在 Windows 使用真实服务商账号做登录／投递验证。自动验收不代表长时间运行、所有显卡和显示缩放均已覆盖。Windows 使用 LLM 翻译；Apple 系统翻译仅限 Mac。Windows 暂不执行 PAC 代理脚本。两端使用各自系统窗口边框和字体渲染，因此不保证跨系统逐像素一致。
