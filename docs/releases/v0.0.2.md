# 轻邮 Lightmail v0.0.2

修复 QQ 邮箱能够连接却收不到邮件的问题，并让界面更容易点选。

- QQ 邮件结构缺少编码信息时仍能正确读取摘要与正文，无需重新生成授权码。
- 设置中的邮箱和翻译配置支持整行点击；侧栏邮箱、文件夹、展开箭头、工具栏、写信按钮及附件的点击范围同步扩大。
- 保留原有账号管理页面与“移除此邮箱”位置。
- README 补充 QQ 授权码获取方法和服务器设置。

每个邮箱仍各自缓存最新 20 封正文，旧邮件摘要保留，超出范围的正文按需读取。

## 下载与升级

需要 Apple Silicon Mac、macOS 15 或更高版本。退出轻邮，解压 `Lightmail-v0.0.2-macos-arm64.zip` 并替换原有应用；邮箱配置和本地数据保留。

这是早期预览版，使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。升级后 macOS 可能要求重新授权钥匙串访问，密码仅在系统弹窗中输入。

`Lightmail-v0.0.2-source.tar.gz` 提供对应源码、QQ 协议兼容补丁与 vendored Rust 依赖；文件完整性可用 `SHA256SUMS.txt` 核对。

## 验证范围

- Rust、Swift、自包含 IMAP/SMTP 与 Chat 接口测试，真实 WebKit 渲染检查，以及 500 次隔离正文读取内存回归检查。
- 隔离示例界面实测账号行空白处、侧栏选择和展开箭头、设置折叠标题、按钮边缘及菜单点击。
- QQ 真实账号收件与正文已验证；QQ 实际发信和长时间运行的内存稳定性仍需更多验证。
