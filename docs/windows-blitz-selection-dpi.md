# Windows 正文选区接口与窗口 DPI 验证

日期：2026-10-02；分支 `fix/windows-blitz-accessible-selection-dpi`。沿用 GPUI Kit + Blitz 与 Windows Credential Manager，不修改 Mac 或共享邮箱业务。

## 已实现

- Document 可访问节点同步当前选区，包含正向与反向端点，使用文本节点 ID 与 Unicode 字符索引。点击清除后不再暴露旧选区。
- 处理 AccessKit `SetTextSelection` 请求，映射到现有文档线程的选择与高亮；辅助工具可选择屏幕外文字，再通过现有复制动作取得正文。
- 字符索引映射为合法 UTF-8 字节边界；忽略未知节点和越界位置，避免旧节点跨邮件操作。可访问文本保留原文尾部空白，另加段落换行，避免节点值和选区索引不一致。
- 可访问节点 ID 映射只属于当前阅读区；换正文时清空，更新可访问树时替换。不引入邮箱记录或收发算法的副本。

## 验证结果

- Windows 26 项行为回归通过，新增中文、组合字符和 emoji 的可访问选区映射、反向选择、未知节点及越界位置检查。
- Rust 核心 56 项通过、4 项按原约定忽略；核心源码与生成绑定无变动。
- 原生窗口验收 34 项通过，另有可见像素检查。独立 UI Automation 客户端读取应用全选区，再发出只选择尾部中文的请求；界面选区和 Windows 剪贴板结果与请求一致。
- 对隔离测试窗口发送 `WM_DPICHANGED`，经历 150%、200% 及原 DPI。验证 GPUI 窗口与阅读 worker 的缩放一致，实际 PNG 像素尺寸正确；保存各阶段截图。没有修改系统显示设置，也没有向其他应用发送消息。
- 向同一测试窗口投递原生 PageDown 键消息，验证焦点路由和正文滚动；Ctrl 组合快捷键仍以动作路径验收，不称为物理键盘已验证。
- 20 封此前授权提取的缓存邮件 × 三种宽度 × 三种 DPI，共 180 组实际产品 worker 绘图、解码和选择检查通过，默认禁图；完整 PNG 仍以有界区域流式导出。
- 本轮包含 DPI 切换的 300 次合成阅读：整应用工作集峰值 117.98 MiB；私有提交内存从前五分之一处 158.91 MiB 到末次 163.96 MiB，增长 5.05 MiB；静置 30 秒后为 163.15 MiB。测试中存在 200% 窗口与额外渲染资源，不能与上一轮只用原 DPI 的峰值直接比较；专用 GPU 显存未计入。

验证目录为忽略的 `build/windows-blitz-selection-dpi-20261002-final/` 与 `build/windows-blitz-selection-dpi-real-private-20261002-final/`。不提交账号库、真实邮件和私密截图；未安装、卸载或推送软件。
